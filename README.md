## 🔥 What I Do

✅ **DevSecOps & Security Automation**  
- Integrating security into CI/CD pipelines using **GitHub Actions, Snyk, Checkov, and Trivy**.  
- Automating compliance checks with **Open Policy Agent (OPA)**.  
- Securing software supply chains using **OWASP Dependency-Check & Snyk**.  

✅ **API & Application Security**  
- Securing **REST & GraphQL APIs** against **OWASP API Top 10 threats**.  
- Using **Burp Suite, OWASP ZAP, and Postman** for API security testing.  
- Implementing **JWT security best practices, rate limiting, WAFs, and mTLS**.  

✅ **Cloud & Container Security**  
- Hardening **Docker containers** and enforcing **least privilege**.  
- Securing **Kubernetes clusters** with **RBAC, Network Policies, and Admission Controllers**.  
- Continuous vulnerability scanning using **Trivy & Snyk**.  

✅ **Offensive Security & Bug Bounty**  
- Hunting for **API vulnerabilities, misconfigurations, and business logic flaws**.  
- Performing **black-box, gray-box, and white-box testing**.  
- Using **ffuf, SQLmap, Metasploit, and Nmap** for reconnaissance and exploitation.
